# Excel Business Brain

**Turn messy spreadsheets into business-ready decisions.**

Excel Business Brain is a Streamlit-based spreadsheet analysis tool.

## V1 Features

- Excel/CSV upload
- Workbook profiling
- Data Health scoring
- Duplicate detection
- Missing-data detection
- Basic type-warning detection
- Conservative data cleaning
- Formula Guardian
- Formula error detection
- Formula pattern inconsistency detection
- Safe formula-gap repair
- Corrected Excel export

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
